Column Details
Column Name Short Name Data Type Data Precision Column Comments
OG_PIPELINE_SEGMENT_PERMIT_ID PPL_S_P_ID NUMBER 10 OG_PIPELINE_SEGMENT_PERMIT_ID is a system generated unique identifier number.
PROJECT_NUMBER PROJ_NUM VARCHAR2 18 PROJECT_NUMBER is a unique business identifier for a pipeline, e.g., 000021886.
SEGMENT_NUMBER SEG_NUM NUMBER 5 SEGMENT_NUMBER is a system generated identification number assigned to each pipeline segment within a pipeline area, e.g., 2.
LINE_TYPE LINE_TYPE VARCHAR2 8 LINE_TYPE is a code indicating the type of pipeline, e.g., TR (Transmission).
LINE_TYPE_DESC LINE_DESC VARCHAR2 60 LINE_TYPE_DESC is a description of the type of pipeline, e.g., Transmission (TR).
PHYSICAL_PIPE_LENGTH PHYS_LEN_M NUMBER 38 PHYSICAL_PIPE_LENGTH is the length of the pipeline segment measured in metres.
STATUS STATUS VARCHAR2 38 STATUS is the status of the activity during the approval process, e.g., Approved.
APPLICATION_DETERMINATION_NUM AD_NUM VARCHAR2 18 APPLICATION_DETERMINATION_NUM is a number assigned to an approved or permitted activity or to a set of activities included in a multi-activity application, e.g., 100082189.
ACTIVITY_APPROVAL_DATE APPRV_DATE DATE 7 ACTIVITY_APPROVAL_DATE is the date the activity was approved by the BC Energy Regulator.
ACTIVITY_CANCEL_DATE CANC_DATE DATE 7 ACTIVITY_CANCEL_DATE is the date the activity was cancelled by the BC Energy Regulator.
LEGACY_OGC_FILE_NUMBER LEGACY_OGC VARCHAR2 16 LEGACY_OGC_FILE_NUMBER is the legacy BCER file number used for referencing applications submitted prior to July 11, 2016, e.g., 9631141.
PROPONENT PROPONENT VARCHAR2 120 PROPONENT is the organization name of the oil and gas operator, e.g., ARC Resources Ltd.
AUTHORITY_TYPE AUTH_TYPE VARCHAR2 8 AUTHORITY_TYPE is the type of authorization issued by the Regulator. Authorizations are issued either under the Energy Resources Activities Act (ERAA) or the Canada Energy Regulator (CER), e.g., ERAA.
DATA_SOURCE DATA_SRC VARCHAR2 10 DATA_SOURCE is the data capture method used to collect the spatial application data submitted to the Regulator, i.e., GPSD (GPS-Differential), GPSND (GPS-Non Differential), ORTHO (Ortho Photography), CGWC (Coordinate Geometry With Control), SNK (Source Not Known).
FEATURE_LENGTH_M LENGTH_M NUMBER 19 FEATURE_LENGTH_M is the system calculated length or perimeter of a geometry in meters.
SHAPE SHAPE SDO_GEOMETRY 1 SHAPE is the column used to reference the spatial coordinates defining the feature.
OBJECTID OBJECTID NUMBER 38 OBJECTID is a required attribute of feature classes and object classes in a geodatabase.
SE_ANNO_CAD_DATA None BLOB 4000 SE_ANNO_CAD_DATA is a binary column used by spatial tools to store annotation, curve features and CAD data when using the SDO_GEOMETRY storage data type.
